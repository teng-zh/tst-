# 文件分享站

一个基于 Flask 的简单文件分享网站，可以上传和下载文件。

## 功能特点

- 📤 文件上传功能
- 📥 文件下载功能
- 📋 已上传文件列表展示
- 🌐 显示本机局域网IP地址
- 🔗 支持通过公网IP访问（需要配置端口映射或使用内网穿透）

## 快速开始

### 1. 安装依赖

```bash
pip install flask
```

### 2. 启动应用

```bash
python app.py
```

### 3. 访问网站

- 本地访问：http://127.0.0.1:5000
- 局域网访问：http://[你的局域网IP]:5000（页面会自动显示）
- 公网访问：需要配置端口映射或使用内网穿透

## 通过公网IP访问

### 方法一：端口映射（推荐）

1. 登录你的路由器管理界面
2. 找到"端口映射"或"虚拟服务器"设置
3. 添加一条映射规则：
   - 外部端口：任意未被占用的端口（如 8080）
   - 内部IP：你的电脑在局域网中的IP地址（如 192.168.3.75）
   - 内部端口：5000
   - 协议：TCP
4. 保存设置后，其他人可以通过你的公网IP:外部端口访问

### 方法二：使用内网穿透服务

#### 使用 ngrok 示例：

1. 下载 ngrok：https://ngrok.com/download
2. 注册并获取 auth token
3. 安装并认证 ngrok：
   ```bash
   ngrok authtoken [你的auth token]
   ```
4. 启动 ngrok 映射到 5000 端口：
   ```bash
   ngrok http 5000
   ```
5. 查看 ngrok 输出的公网URL，其他人可以通过这个URL访问

## 配置说明

在 `app.py` 中可以修改以下配置：

- `UPLOAD_FOLDER`：上传文件保存目录，默认为 `uploads`
- `MAX_CONTENT_LENGTH`：最大文件大小限制，默认为 16MB
- 运行端口：默认为 5000，可以在 `app.run()` 中修改

## 注意事项

- 确保防火墙允许 5000 端口的入站连接
- 应用运行在开发模式下，请勿在生产环境直接使用
- 定期清理上传目录中的文件，避免占用过多磁盘空间
- 使用公网访问时请注意网络安全
